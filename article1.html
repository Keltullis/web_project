Детство и юность

Линус Бенедикт Торвальдс родился 28 декабря 1969 года в Хельсинки, Финляндия. Родители — журналисты. Имя Линус он получил в честь химика Лайнуса Полинга.

Первую программу он написал в 11 лет на языке BASIC.

Университетские годы

В 1988 году Линус поступил в Хельсинкский университет. Там он познакомился с системой MINIX.

Рождение Linux

В августе 1991 года Торвальдс объявил о своём проекте. Первая версия — Linux 0.01 — вышла 17 сентября 1991 года.

Изначально ядро хотели назвать Freax Linux.

Создание Git

В апреле 2005 года Торвальдс создал систему контроля версий Git.

Основные команды: git init, git commit, git push, git pull.

Наши дни

Сегодня Линус Торвальдс — главный сопровождающий ядра Linux.

По его словам: Я не вижу снов о коде. Я вижу сны о том, чтобы поспать ещё немного. — Линус Торвальдс
