Список терминов

Дата публикации: 13 сентября 2026

Основные термины, связанные с деятельностью Линуса Торвальдса.

Основные понятия

Ядро (kernel)
Центральная часть ОС, управляющая ресурсами компьютера.
Linux
Свободное ядро, созданное Торвальдсом в 1991 году.
GNU/Linux
ОС из ядра Linux и утилит проекта GNU.
Дистрибутив
Набор ПО на основе ядра Linux: Ubuntu, Fedora, Debian.
GPL
Свободная лицензия, гарантирующая право запускать, изучать и распространять ПО.
Open Source
Модель разработки ПО с открытым исходным кодом.

Термины, связанные с Git

Git
Распределённая система контроля версий, созданная Торвальдсом в 2005 году.
Репозиторий
Хранилище проекта с историей изменений. Создаётся командой git init.
Коммит
Зафиксированное изменение. Создаётся командой git commit.
Ветка (branch)
Отдельная линия разработки.
Удалённый репозиторий
Копия репозитория на сервере. Синхронизация — git push и git pull.

Прочие термины

Компилятор
Программа, переводящая исходный код в машинный. Ядро Linux написано на C.
Суперкомпьютер
Вычислительная машина высокой производительности. Около 99 % из TOP500 работают под Linux.
Maintainer
Разработчик, отвечающий за часть проекта. Линус Торвальдс — главный сопровождающий ядра Linux.
