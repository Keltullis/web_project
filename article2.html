Ядро Linux

Главное изобретение Торвальдса — свободное ядро Linux, начатое в 1991 году. Сегодня оно используется:

  • на 99 % суперкомпьютеров TOP500;
  • в основе мобильной ОС Android;
  • на большинстве веб-серверов;
  • во встраиваемых устройствах.

Система контроля версий Git

В 2005 году Торвальдс создал Git — распределённую систему контроля версий. Первая версия была написана всего за две недели.

Базовые команды:

  1. git init — создать репозиторий;
  2. git commit — зафиксировать изменения;
  3. git push — отправить на сервер;
  4. git pull — получить изменения.
